   131	        ``pytest.raises(Exc, func, match="passed on").match("my pattern")``.)

   137	        If specified, a callable that will be called with the exception as a parameter

   143	    Use ``pytest.raises`` as a context manager, which will capture the exception of the given
   144	    type, or any of its subclasses::

   163	    `PEP-678 <https://peps.python.org/pep-0678/>`__ ``__notes__``:
