  3846	    semantic analyzer. These are created if some essential dependencies
  3847	    of a definition are not yet complete.

  3850	    incomplete (within an import cycle):
  3851
  3852	      from m import f  # Initially may create PlaceholderNode

  3855	    an enclosing scope or builtins:
  3856
  3857	      from m import int  # Placeholder avoids mixups with builtins.int

  3862	      from m import f

  3870
  3871	      class C(Sequence[C]): ...
