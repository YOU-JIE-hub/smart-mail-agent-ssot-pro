 the existence of module 'package.mod'. This
    44	  gets triggered if 'package.mod' is created or deleted, or if it gets
    45	  changed into something other than a module.
    46
    47	Examples of locations:
    48
    49	* 'mod' is the top level of module 'mod' (doesn't include any function bodies,
    50	  but includes class bodies not nested within a function).
    51	* 'mod.f' is function 'f' in module 'mod' (module-level variables aren't separate
    52	  locations but are included in the module top level). Functions also include
    53	  any nested functions and classes -- such nested definitions aren't separate
    54	  locations, for simplicity of implementation.
    55	* 'mod.Cls.f' is method 'f' of 'mod.Cls'. Non-method attributes aren't locations.
    56	* 'mod.Cls' represents each method in class 'mod.Cls' + the top-level of the
    57	  module 'mod'. (To simplify the implementation, there is no location that only
    58	  includes the body of a class without the entire surrounding module top level.)
    59	* Trigger '<...>' as a location is an indirect way of referring to all
    60	  locations triggered by the trigger. These indirect locations keep the
    61	  dependency map smaller and easier to manage.
    62
    63	Triggers can be triggered by program changes such as these:
    64
    65	* Addition or deletion of an attribute (or module).
    66	* Change of the kind of thing a name represents (such as a change from a function
    67	  to a class).
    68	* Change of the static type of a name.
    69
    70	Changes in the body of a function that aren't reflected in the signature don't
    71	cause the function to be triggered. More generally, we trigger only on changes
    72	that may affect type checking results outside the module that contains the
    73	change.
    74
    75	We don't generate dependencies from builtins and certain other stdlib modules,
    76	since these change very rarely, and they would just increase the size of the
    77	dependency map significantly without significant benefit.
    78
    79	Test cases for this module live in 'test-data/unit/deps*.test'.
    80	"""

   179	def get_dependencies(
   180	    target: MypyFile,
   181	    type_map: dict[Expression, Type],
   182	    python_version: tuple[int, int],
   183	    options: Options,
   184	) -> dict[str, set[str]]:
   185	    """Get all dependencies of a node, recursively."""

   191	def get_dependencies_of_target(
   192	    module_id: str,
   193	    module_tree: MypyFile,
   194	    target: Node,
   195	    type_map: dict[Expression, Type],
   196	    python_version: tuple[int, int],
   197	) -> dict[str, set[str]]:
   198	    """Get dependencies of a target -- don't recursive into nested targets."""
   199	    # TODO: Add tests for this function.
   200	    visitor = DependencyVisitor(type_map, python_version, module_tree.alias_deps)
   201	    with visitor.scope.module_scope(module_id):
   202	        if isinstance(target, MypyFile):
   203	            # Only get dependencies of the top-level of the module. Don't recurse into
   204	            # functions.
   205	            for defn in target.defs:
   206	                # TODO: Recurse into top-level statements and class bodies but skip functions.
   207	                if not isinstance(defn, (ClassDef, Decorator, FuncDef, OverloadedFuncDef)):
   208	                    defn.accept(visitor)
   209	        elif isinstance(target, FuncBase) and target.info:
   210	            # It's a method.
   211	            # TODO: Methods in nested classes.
   212	            with visitor.scope.class_scope(target.info):
   213	                target.accept(visitor)
   214	        else:
   215	            target.accept(visitor)
   216	    return visitor.map

   219	class DependencyVisitor(TraverserVisitor):
   220	    def __init__(
   221	        self,
   222	        type_map: dict[Expression, Type],
   223	        python_version: tuple[int, int],
   224	        alias_deps: defaultdict[str, set[str]],
   225	        options: Options | None = None,
   226	    ) -> None:
   227	        self.scope = Scope()
   228	        self.type_map = type_map
   229	        # This attribute holds a mapping from target to names of type aliases
   230	        # it depends on. These need to be processed specially, since they are
   231	        # only present in expanded form in symbol tables. For example, after:
   232	        #    A = List[int]
   233	        #    x: A
   234	        # The module symbol table will just have a Var `x` with type `List[int]`,
   235	        # and the dependency of `x` on `A` is lost. Therefore the alias dependencies
   236	        # are preserved at alias expansion points in `semanal.py`, stored as an attribute
   237	        # on MypyFile, and then passed here.
   238	        self.alias_deps = alias_deps
   239	        self.map: dict[str, set[str]] = {}
   240	        self.is_class = False
   241	        self.is_package_init_file = False
   242	        self.options = options
   243
   244	    def visit_mypy_file(self, o: MypyFile) -> None:
   245	        with self.scope.module_scope(o.fullname):
   246	            self.is_package_init_file = o.is_package_init_file()
   247	            self.add_type_alias_deps(self.scope.current_target())
   248	            for trigger, targets in o.plugin_deps.items():
   249	                self.map.setdefault(trigger, set()).update(targets)
   250	            super().visit_mypy_file(o)
   251
   252	    def visit_func_def(self, o: FuncDef) -> None:
   253	        with self.scope.function_scope(o):
   254	            target = self.scope.current_target()
   255	            if o.type:
   256	                if self.is_class and isinstance(o.type, FunctionLike):
   257	                    signature: Type = bind_self(o.type)
   258	                else:
   259	                    signature = o.type
   260	                for trigger in self.get_type_triggers(signature):
   261	                    self.add_dependency(trigger)
   262	                    self.add_dependency(trigger, target=make_trigger(target))
   263	            if o.info:
   264	                for base in non_trivial_bases(o.info):
   265	                    # Base class __init__/__new__ doesn't generate a logical
   266	                    # dependency since the override can be incompatible.
   267	                    if not self.use_logical_deps() or o.name not in ("__init__", "__new__"):
   268	                        self.add_dependency(make_trigger(base.fullname + "." + o.name))
   269	            self.add_type_alias_deps(self.scope.current_target())
   270	            super().visit_func_def(o)
   271	            variants = set(o.expanded) - {o}
   272	            for ex in variants:
   273	                if isinstance(ex, FuncDef):
   274	                    super().visit_func_def(ex)
   275
   276	    def visit_decorator(self, o: Decorator) -> None:
   277	        if not self.use_logical_deps():
   278	            # We don't need to recheck outer scope for an overload, only overload itself.
   279	            # Also if any decorator is nested, it is not externally visible, so we don't need to
   280	            # generate dependency.
   281	            if not o.func.is_overload and self.scope.current_function_name() is None:
   282	                self.add_dependency(make_trigger(o.func.fullname))
   283	        else:
   284	            # Add logical dependencies from decorators to the function. For example,
   285	            # if we have
   286	            #     @dec
   287	            #     def func(): ...
   288	            # then if `dec` is unannotated, then it will "spoil" `func` and consequently
   289	            # all call sites, making them all `Any`.
   290	            for d in o.decorators:
   291	                tname: str | None = None
   292	                if isinstance(d, RefExpr) and d.fullname:
   293	                    tname = d.fullname
   294	                if isinstance(d, CallExpr) and isinstance(d.callee, RefExpr) and d.callee.fullname:
   295	                    tname = d.callee.fullname
   296	                if tname is not None:
   297	                    self.add_dependency(make_trigger(tname), make_trigger(o.func.fullname))
   298	        super().visit_decorator(o)
   299
   300	    def visit_class_def(self, o: ClassDef) -> None:
   301	        with self.scope.class_scope(o.info):
   302	            target = self.scope.current_full_target()
   303	            self.add_dependency(make_trigger(target), target)
   304	            old_is_class = self.is_class
   305	            self.is_class = True
   306	            # Add dependencies to type variables of a generic class.
   307	            for tv in o.type_vars:
   308	                self.add_dependency(make_trigger(tv.fullname), target)
   309	            self.process_type_info(o.info)
   310	            super().visit_class_def(o)
   311	            self.is_class = old_is_class
   312
   313	    def visit_newtype_expr(self, o: NewTypeExpr) -> None:
   314	        if o.info:
   315	            with self.scope.class_scope(o.info):
   316	                self.process_type_info(o.info)

   318	    def process_type_info(self, info: TypeInfo) -> None:
   319	        target = self.scope.current_full_target()
   320	        for base in info.bases:
   321	            self.add_type_dependencies(base, target=target)
   322	        if info.tuple_type:
   323	            self.add_type_dependencies(info.tuple_type, target=make_trigger(target))
   324	        if info.typeddict_type:
   325	            self.add_type_dependencies(info.typeddict_type, target=make_trigger(target))
   326	        if info.declared_metaclass:
   327	            self.add_type_dependencies(info.declared_metaclass, target=make_trigger(target))
   328	        if info.is_protocol:
   329	            for base_info in info.mro[:-1]:
   330	                # We add dependencies from whole MRO to cover explicit subprotocols.
   331	                # For example:
   332	                #
   333	                #     class Super(Protocol):
   334	                #         x: int
   335	                #     class Sub(Super, Protocol):
   336	                #         y: int
   337	                #
   338	                # In this example we add <Super[wildcard]> -> <Sub>, to invalidate Sub if
   339	                # a new member is added to Super.
   340	                self.add_dependency(
   341	                    make_wildcard_trigger(base_info.fullname), target=make_trigger(target)
   342	                )
   343	                # More protocol dependencies are collected in type_state._snapshot_protocol_deps
   344	                # after a full run or update is finished.
   345
   346	        self.add_type_alias_deps(self.scope.current_target())
   347	        for name, node in info.names.items():
   348	            if isinstance(node.node, Var):
   349	                # Recheck Liskov if needed, self definitions are checked in the defining method
   350	                if node.node.is_initialized_in_class and has_user_bases(info):
   351	                    self.add_dependency(make_trigger(info.fullname + "." + name))
   352	                for base_info in non_trivial_bases(info):
   353	                    # If the type of an attribute changes in a base class, we make references
   354	                    # to the attribute in the subclass stale.
   355	                    self.add_dependency(
   356	                        make_trigger(base_info.fullname + "." + name),
   357	                        target=make_trigger(info.fullname + "." + name),
   358	                    )
   359	        for base_info in non_trivial_bases(info):
   360	            for name, node in base_info.names.items():
   361	                if self.use_logical_deps():
   362	                    # Skip logical dependency if an attribute is not overridden. For example,
   363	                    # in case of:
   364	                    #     class Base:
   365	                    #         x = 1
   366	                    #         y = 2
   367	                    #     class Sub(Base):
   368	                    #         x = 3
   369	                    # we skip <Base.y> -> <Child.y>, because even if `y` is unannotated it
   370	                    # doesn't affect precision of Liskov checking.
   371	                    if name not in info.names:
   372	                        continue
   373	                    # __init__ and __new__ can be overridden with different signatures, so no
   374	                    # logical dependency.
   375	                    if name in ("__init__", "__new__"):
   376	                        continue
   377	                self.add_dependency(
   378	                    make_trigger(base_info.fullname + "." + name),
   379	                    target=make_trigger(info.fullname + "." + name),
   380	                )
   381	            if not self.use_logical_deps():
   382	                # These dependencies are only useful for propagating changes --
   383	                # they aren't logical dependencies since __init__ and __new__ can be
   384	                # overridden with a different signature.
   385	                self.add_dependency(
   386	                    make_trigger(base_info.fullname + ".__init__"),
   387	                    target=make_trigger(info.fullname + ".__init__"),
   388	                )
   389	                self.add_dependency(
   390	                    make_trigger(base_info.fullname + ".__new__"),
   391	                    target=make_trigger(info.fullname + ".__new__"),
   392	                )
   393	                # If the set of abstract attributes change, this may invalidate class
   394	                # instantiation, or change the generated error message, since Python checks
   395	                # class abstract status when creating an instance.
   396	                self.add_dependency(
   397	                    make_trigger(base_info.fullname + ".(abstract)"),
   398	                    target=make_trigger(info.fullname + ".__init__"),
   399	                )
   400	                # If the base class abstract attributes change, subclass abstract
   401	                # attributes need to be recalculated.
   402	                self.add_dependency(make_trigger(base_info.fullname + ".(abstract)"))
   403
   404	    def visit_import(self, o: Import) -> None:
   405	        for id, as_id in o.ids:
   406	            self.add_dependency(make_trigger(id), self.scope.current_target())

   408	    def visit_import_from(self, o: ImportFrom) -> None:
   409	        if self.use_logical_deps():
   410	            # Just importing a name doesn't create a logical dependency.
   411	            return
   412	        module_id, _ = correct_relative_import(
   413	            self.scope.current_module_id(), o.relative, o.id, self.is_package_init_file
   414	        )
   415	        self.add_dependency(make_trigger(module_id))  # needed if module is added/removed
   416	        for name, as_name in o.names:
   417	            self.add_dependency(make_trigger(module_id + "." + name))
   418
   419	    def visit_import_all(self, o: ImportAll) -> None:
   420	        module_id, _ = correct_relative_import(
   421	            self.scope.current_module_id(), o.relative, o.id, self.is_package_init_file
   422	        )
   423	        # The current target needs to be rechecked if anything "significant" changes in the
   424	        # target module namespace (as the imported definitions will need to be updated).
   425	        self.add_dependency(make_wildcard_trigger(module_id))
