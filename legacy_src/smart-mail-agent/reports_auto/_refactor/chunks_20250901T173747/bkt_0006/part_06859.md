    38
    39	    `patch` is an iterable of 2-tuples (key, value):
    40	        `key`: string
    41	        `value`:
    42	            - string: `environ[key] == value` inside the context.

    52	            env.pop(k, None)

    54	            env[k] = format_env(v, before)
    55	        else:
    56	            env[k] = v

    59	        yield
    60	    finally:

    34	                    # attempts.

    36	                        raise
    37	                else:
    38	                    break

    41	            yield

    44	            # closed so this may not be necessary.
    45	            # The documentation however states:
    46	            # "Regions should be locked only briefly and should be unlocked
