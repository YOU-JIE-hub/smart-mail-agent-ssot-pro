     2
     3	Most of the ops can be automatically generated by matching against AST
     4	nodes and types. For example, a func_op is automatically generated when
     5	a specific function is called with the specific positional argument
     6	count and argument types.
     7
     8	Example op definition:
     9
    10	list_len_op = func_op(name='builtins.len',
    11	                      arg_types=[list_rprimitive],
    12	                      result_type=short_int_rprimitive,
    13	                      error_kind=ERR_NEVER,
    14	                      emit=emit_len)
    15
    16	This op is automatically generated for calls to len() with a single
    17	list argument. The result type is short_int_rprimitive, and this
    18	never raises an exception (ERR_NEVER). The function emit_len is used
    19	to generate C for this op.  The op can also be manually generated using
    20	"list_len_op". Ops that are only generated automatically don't need to
    21	be assigned to a module attribute.
    22
    23	Ops defined with custom_op are only explicitly generated in
    24	mypyc.irbuild and won't be generated automatically. They are always
    25	assigned to a module attribute, as otherwise they won't be accessible.
    26
    27	The actual ops are defined in other submodules of this package, grouped
    28	by category.

    31	arguments and types. For example, there are generic implementations of
    32	arbitrary function and method calls, and binary operators. These generic

    34	to rely on them for infrequently used ops. It's impractical to have

    88	def method_op(
    89	    name: str,
    90	    arg_types: list[RType],
    91	    return_type: RType,
    92	    c_function_name: str,
    93	    error_kind: int,
    94	    var_arg_type: RType | None = None,
    95	    truncated_type: RType | None = None,
    96	    ordering: list[int] | None = None,
    97	    extra_int_constants: list[tuple[int, RType]] | None = None,
    98	    steals: StealsDescription = False,
    99	    is_borrowed: bool = False,
   100	    priority: int = 1,
   101	    is_pure: bool = False,
   102	) -> PrimitiveDescription:
   103	    """Define a c function call op that replaces a method call.
   104
   105	    This will be automatically generated by matching against the AST.
   106
   107	    Args:
   108	        name: short name of the method (for example, 'append')
   109	        arg_types: argument types; the receiver is always the first argument
   110	        return_type: type of the return value. Use void_rtype to represent void.
   111	        c_function_name: name of the C function to call
   112	        error_kind: how errors are represented in the result (one of ERR_*)
   113	        var_arg_type: type of all variable arguments
   114	        truncated_type: type to truncated to(See Truncate for info)
   115	                        if it's defined both return_type and it should be non-referenced
   116	                        integer types or bool type
   117	        ordering: optional ordering of the arguments, if defined,
   118	                  reorders the arguments accordingly.
   119	                  should never be used together with var_arg_type.
   120	                  all the other arguments(such as arg_types) are in the order
   121	                  accepted by the python syntax(before reordering)
   122	        extra_int_constants: optional extra integer constants as the last arguments to a C call
   123	        steals: description of arguments that this steals (ref count wise)
   124	        is_borrowed: if True, returned value is borrowed (no need to decrease refcount)
   125	        priority: if multiple ops match, the one with the highest priority is picked
   126	        is_pure: if True, declare that the C function has no side effects, takes immutable
   127	                 arguments, and never raises an exception
   128	    """
   129	    if extra_int_constants is None:
   130	        extra_int_constants = []
   131	    ops = method_call_ops.setdefault(name, [])
   132	    desc = PrimitiveDescription(
   133	        name,
   134	        arg_types,
   135	        return_type,
   136	        var_arg_type,
   137	        truncated_type,
   138	        c_function_name,
   139	        error_kind,
   140	        steals,
   141	        is_borrowed,
   142	        ordering,
   143	        extra_int_constants,
   144	        priority,
   145	        is_pure=is_pure,
   146	    )
   147	    ops.append(desc)
   148	    return desc
