  1603	class KeepAlive(RegisterOp):

  1605

  1607	    being held but not seen by the compiler.
  1608
  1609	    A typical use case is like this (C-like pseudocode):
  1610
  1611	      ptr = &x.item
  1612	      r = *ptr
  1613	      keep_alive x  # x must not be freed here
  1614	      # x may be freed here

  1617	    after taking the address of 'item', resulting in a read after free
  1618	    on the second line.

  1621	    this op, i.e. it won't be decref'd. You need to ensure that
  1622	    the value is freed otherwise, perhaps by using borrowing
  1623	    followed by Unborrow.

  1632	        self.src = src

  1652
  1653	    Borrowed references can only be used temporarily and the reference
  1654	    counts won't be managed. This value will be refcounted normally.
  1655

  1669	      # managed again. (Note we need to steal before unborrow, to avoid

  1854	# We do a three-pass deserialization scheme in order to resolve name
  1855	# references.
  1856	#  1. Create an empty ClassIR for each class in an SCC.
  1857	#  2. Deserialize all of the functions, which can contain references
  1858	#     to ClassIRs in their types
  1859	#  3. Deserialize all of the classes, which contain lots of references
  1860	#     to the functions they contain. (And to other classes.)
  1861	#
  1862	# Note that this approach differs from how we deserialize ASTs in mypy itself,
  1863	# where everything is deserialized in one pass then a second pass cleans up
  1864	# 'cross_refs'. We don't follow that approach here because it seems to be more
  1865	# code for not a lot of gain since it is easy in mypyc to identify all the objects
  1866	# we might need to reference.
  1867	#
  1868	# Because of these references, we need to maintain maps from class
  1869	# names to ClassIRs and func IDs to FuncIRs.
  1870	#
  1871	# These are tracked in a DeserMaps which is passed to every
  1872	# deserialization function.
  1873	#
  1874	# (Serialization and deserialization *will* be used for incremental
  1875	# compilation but so far it is not hooked up to anything.)
  1876	class DeserMaps(NamedTuple):
  1877	    classes: dict[str, ClassIR]
  1878	    functions: dict[str, FuncIR]
