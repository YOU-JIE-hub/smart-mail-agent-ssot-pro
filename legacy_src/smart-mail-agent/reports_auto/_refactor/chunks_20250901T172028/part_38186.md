   352	class SnapshotTypeVisitor(TypeVisitor[SnapshotItem]):
   353	    """Creates a read-only, self-contained snapshot of a type object.
   354
   355	    Properties of a snapshot:
   356
   357	    - Contains (nested) tuples and other immutable primitive objects only.
   358	    - References to AST nodes are replaced with full names of targets.
   359	    - Has no references to mutable or non-primitive objects.
   360	    - Two snapshots represent the same object if and only if they are
   361	      equal.

   363	      consistent types and can't arbitrarily mix str and None values,
   364	      for example, since they can't be compared.
