     2
     3	When the source code of a module has a change in fine-grained incremental mode,
     4	we build a new AST from the updated source. However, other parts of the program
     5	may have direct references to parts of the old AST (namely, those nodes exposed
     6	in the module symbol table). The merge operation changes the identities of new
     7	AST nodes that have a correspondence in the old AST to the old ones so that
     8	existing cross-references in other modules will continue to point to the correct
     9	nodes. Also internal cross-references within the new AST are replaced. AST nodes
    10	that aren't externally visible will get new, distinct object identities. This
    11	applies to most expression and statement nodes, for example.
    12
    13	We perform this merge operation so that we don't have to update all
    14	external references (which would be slow and fragile) or always perform
    15	translation when looking up references (which would be hard to retrofit).
    16
    17	The AST merge operation is performed after semantic analysis. Semantic
    18	analysis has to deal with potentially multiple aliases to certain AST
    19	nodes (in particular, MypyFile nodes). Type checking assumes that we
    20	don't have multiple variants of a single AST node visible to the type
    21	checker.
    22

    24
    25	* If a node is replaced with a different kind of node (say, a function is
    26	  replaced with a class), we don't perform the merge. Fine-grained dependencies
    27	  will be used to rebind all references to the node.

   116	def merge_asts(
   117	    old: MypyFile, old_symbols: SymbolTable, new: MypyFile, new_symbols: SymbolTable
   118	) -> None:
   119	    """Merge a new version of a module AST to a previous version.
   120
   121	    The main idea is to preserve the identities of externally visible
   122	    nodes in the old AST (that have a corresponding node in the new AST).
   123	    All old node state (outside identity) will come from the new AST.
   124
   125	    When this returns, 'old' will refer to the merged AST, but 'new_symbols'
   126	    will be the new symbol table. 'new' and 'old_symbols' will no longer be
   127	    valid.
   128	    """
   129	    assert new.fullname == old.fullname
   130	    # Find the mapping from new to old node identities for all nodes
   131	    # whose identities should be preserved.
   132	    replacement_map = replacement_map_from_symbol_table(
   133	        old_symbols, new_symbols, prefix=old.fullname
   134	    )
   135	    # Also replace references to the new MypyFile node.
   136	    replacement_map[new] = old
   137	    # Perform replacements to everywhere within the new AST (not including symbol
   138	    # tables).
   139	    node = replace_nodes_in_ast(new, replacement_map)
   140	    assert node is old
   141	    # Also replace AST node references in the *new* symbol table (we'll
   142	    # continue to use the new symbol table since it has all the new definitions
   143	    # that have no correspondence in the old AST).
   144	    replace_nodes_in_symbol_table(new_symbols, replacement_map)

   147	def replacement_map_from_symbol_table(
   148	    old: SymbolTable, new: SymbolTable, prefix: str
   149	) -> dict[SymbolNode, SymbolNode]:
   150	    """Create a new-to-old object identity map by comparing two symbol table revisions.
   151
   152	    Both symbol tables must refer to revisions of the same module id. The symbol tables
   153	    are compared recursively (recursing into nested class symbol tables), but only within
   154	    the given module prefix. Don't recurse into other modules accessible through the symbol
   155	    table.
   156	    """
   157	    replacements: dict[SymbolNode, SymbolNode] = {}
   158	    for name, node in old.items():
   159	        if name in new and (
   160	            node.kind == MDEF or node.node and get_prefix(node.node.fullname) == prefix
   161	        ):
   162	            new_node = new[name]
   163	            if (
   164	                type(new_node.node) == type(node.node)
   165	                and new_node.node
   166	                and node.node
   167	                and new_node.node.fullname == node.node.fullname
   168	                and new_node.kind == node.kind
   169	            ):
   170	                replacements[new_node.node] = node.node
   171	                if isinstance(node.node, TypeInfo) and isinstance(new_node.node, TypeInfo):
   172	                    type_repl = replacement_map_from_symbol_table(
   173	                        node.node.names, new_node.node.names, prefix
   174	                    )
   175	                    replacements.update(type_repl)
   176	                    if node.node.special_alias and new_node.node.special_alias:
   177	                        replacements[new_node.node.special_alias] = node.node.special_alias
   178	    return replacements
