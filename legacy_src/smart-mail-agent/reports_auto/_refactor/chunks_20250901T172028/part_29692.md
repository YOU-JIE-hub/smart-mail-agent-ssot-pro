   210
   211	    Specifically, there are currently exactly three different types that can have
   212	    "variants" or are "union-like":

   224	    we return a list containing that TypeVarLike's upper bound.

   227	    the algorithm to check if two unions are overlapping is fundamentally the same as
   228	    the algorithm for checking if two overloads are overlapping.

   252	        # infer a too-specific return type of List[CallableType]

   326	            overlap_for_overloads=overlap_for_overloads,
